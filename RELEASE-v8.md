# Rede Lua Educação v8.0 — Nova Plataforma

## Mudança de produto

A v8 inicia a reconstrução do frontend: Home, Aprender, Studio, LuaID e Suporte foram redesenhados, com novo shell responsivo e navegação própria.

## Aprender

- sessão guiada persistida no backend;
- resposta errada não revela gabarito;
- pistas progressivas;
- campo opcional de raciocínio;
- pular sem revelar resposta;
- explicação e XP somente após chegar à resposta correta.

## Studio

- criação por etapas;
- templates de mini-games;
- preview de visual/regras;
- Batalha de Chefão, Caça ao Tesouro, Corrida Espacial e Duelo de Cartas;
- biblioteca, sala ao vivo e insights continuam integrados.

## LuaID

- handle único;
- manifesto próprio da Rede Lua;
- API pública limitada para perfis de sala;
- base visual DiceBear mantida, mas perfil/progresso/tema pertencem à Rede Lua.

## Suporte

- página nova;
- e-mails do domínio apresentados no produto;
- Cloudflare Function para contato;
- armazenamento opcional no Supabase;
- envio opcional por Resend;
- caixa de suporte no Rede Lua Control.

## Compatibilidade

A v8 preserva banco e histórico das versões anteriores.
