# Rede Lua Educação v6.7 — Mais Humana

A home pública foi refeita para parecer menos “produto de IA” e mais uma plataforma escolar viva.

## O que mudou
- Hero com texto curto e direto, sem jargões de tecnologia.
- Entrada por código virou a ação principal.
- Exemplo visual de uma partida com professor, aluno, reações e pergunta.
- Nova seção “Como funciona” em linguagem comum.
- Cards de perfil, tema do quiz e reações com tom mais divertido.
- Área pública para professores explicada sem termos técnicos.
- Recomendações com microcopy mais natural.
- Home mais compacta no celular.
- Footer com texto menos institucional.

Nenhum recurso de backend foi removido. LuaCore, Supabase, Quiz Studio, perfis, Sala Viva e demais sistemas continuam funcionando por trás.
